### 📌 Featured project

#### [Snap-Through Buckling of a Hexagonal Unit Cell (Nonlinear FEM with Abaqus)](https://github.com/chinmayeechogale/Snap-Through-Bucking-Non-Linear-FEM-with-Abaqus-)
<a href="https://github.com/chinmayeechogale/Snap-Through-Bucking-Non-Linear-FEM-with-Abaqus-"><img src="https://raw.githubusercontent.com/chinmayeechogale/Snap-Through-Bucking-Non-Linear-FEM-with-Abaqus-/main/results/figures/peak_force_envelope.png" width="480" alt="Peak-force envelope of the unit cell"></a>

Collapse, snap-through and energy absorption of a thin-walled aluminium cell under 25 cycles of growing compression.
- **Nonlinear FEA in Abaqus/Standard:** large deformation, elastic-plastic material, contact, stabilized Newton-Raphson
- **Automation:** Abaqus Python script that pulls force-displacement data from the output database
- **Post-processing:** Python and MATLAB scripts for cycle peaks, energy balance and plots
- **Result:** 5.64 kN collapse load, 57% load drop, about 170 J dissipated
